## Pull, Commit, and Push Changes

Before starting work, open a terminal in the project folder and pull the latest
changes from GitHub:

```bash
git pull origin main
```

After editing and saving your files, review and stage your changes:

```bash
git status
git add .
```

Commit the staged changes with a short, descriptive message:

```bash
git commit -m "Describe your changes"
```

Push the commit to GitHub:

```bash
git push origin main
```

Replace `main` with the name of your branch if you are working on a different
branch.
